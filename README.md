# projeto-final-HIoT
Este repositório contém as informações e os materiais utilizados para o projeto final da disciplina IMD0904 - PLATAFORMAS DE HARDWARE PARA INTERNET DAS COISAS, lecionada pelo professor Luiz de França

O Projeto envolve a criação, com a utilização de um ESP32. de um sistema de iluminação baseada em toque, para facilitar o acesso a luz em diversos casos.
